# FieldSense contributor instructions

For ongoing FieldSense work:

- Read `docs/PRODUCT_ROADMAP.md` and `docs/PROGRESS.md` before implementing roadmap features.
- Follow the user's current scope; the roadmap alone is not an instruction to implement every feature.
- Update `docs/PROGRESS.md` with each meaningful implementation increment: status, actual validation, remaining limitations, decisions and next step.
- Keep completed capabilities distinct from demonstrations, placeholders and planned integrations.
- Preserve farmer evidence and its provenance. Permanent history, real dates and reliable storage take priority over additional dashboard decoration.
- Update the README and roadmap when an implemented change materially alters their descriptions.
